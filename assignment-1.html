01 / GET READY

先開 Canvas，再說清楚你要什麼。

不用先背完語法，
先學會提出需求、觀察結果與給回饋。

工具

開啟 Gemini，確認可使用 Canvas（畫布）。用對話提出需求，查看作品預覽與程式碼。操作方式可參考 Canvas 官方說明 ↗。

角色設定＋遊戲類型＋核心玩法與規則＋視覺風格與 UI

例如，這樣說就比「做個遊戲」清楚。

請扮演資深HTML5遊戲工程師，製作一個復古像素風打磚塊遊戲。底部滑塊用左右方向鍵控制，頂部有三排磚塊。球撞到磚塊時，磚塊消失並加分。

02 / MAKE IT PLAYABLE

先做能玩的基本版，再疊加功能。

MVP（最小可行版本）：先讓核心玩法能動，
再逐項加入功能。

步驟 1 / 打磚塊 MVP

第一段，貼進 Gemini Canvas。

請扮演資深HTML5網頁遊戲開發者，製作單一HTML檔案的「經典打磚塊遊戲」，CSS和JavaScript全部放在同一個檔案內。

1. 畫面中央放一個遊戲畫布。
2. 玩家用鍵盤左、右方向鍵移動底部滑塊。
3. 上方有三排彩色磚塊，小球碰到磚塊時磚塊消失，每塊加10分。
4. 小球掉到底部邊界時，顯示Game Over。
5. 使用深色科技風格，搭配明亮的顏色。
請先完成以上基本功能，讓我可以直接在Canvas預覽並試玩。
第一個驗收點

點進作品預覽，測試左右方向鍵、球與磚塊碰撞、加分及 Game Over。核心玩法能動了，再加入下一項需求。

步驟 2 / 每次給一組追加指令。

2-1 / 遊戲機制

加入生命與重新開始。

請加入3條生命。小球掉出底部時扣1條生命，歸零才Game Over。新增「重新開始」按鈕，重設分數、生命與遊戲狀態。
2-2 / 主題與視覺

從打磚塊，長出你的風格。

將主題改成太空科幻風：使用深藍色背景與閃爍星星，滑塊變成太空船，小球變成發光能量球。新增最高分紀錄。保留目前的玩法與生命系統。
2-3 / 進階挑戰：道具掉落
擊碎磚塊時，有20%機率掉落道具。滑塊接到道具後變長，5秒後恢復原本長度。請保留原有功能。

03 / DEBUG

遇到問題，就把現象說具體。

說出發生的情境與預期行為，
讓 AI 知道要修哪裡。

01 邊界問題
按住右方向鍵時，滑塊會超出畫面右邊。請加入左右邊界限制，讓滑塊不能移出畫布，保留其他玩法。
02 難度微調
現在小球的初始速度太快，請調慢30%，讓剛開始玩的人也能接到球，保留其他功能。
03 卡住或運作錯誤
當小球掉到底部時畫面會卡住，無法繼續。請修正這個問題，並用註解說明原因。修正後測試失去生命、Game Over與重新開始，確認都能重複操作。

把想像說得更具體，可以用這些關鍵字。

  • 風格：復古街機、賽博朋克、極簡、手繪。
  • 操作：手機觸控、AD／WS、滑鼠跟隨。
  • 效果：Web Audio 音效、粒子爆炸。
  • 邏輯：漸進難度、關卡、排行榜。

04 / CHOOSE & BUILD

課堂練習，二選一。

從零製作自己的版本，
試玩、追加功能、除錯，再下載。

挑戰 A

經典貪食蛇

請製作單一HTML檔案的經典貪食蛇遊戲，CSS與JavaScript內嵌。
1. 用鍵盤上下左右鍵控制蛇移動。
2. 隨機生成紅色蘋果；吃到蘋果後，蛇長度加1、分數加10。
3. 撞牆或撞到自己的身體時Game Over。
4. 右上角即時顯示分數與最高分。
5. 採復古街機風格。
挑戰 B

太空射擊遊戲

請製作單一HTML檔案的2D直向太空射擊遊戲，CSS與JavaScript內嵌。
1. 用左右鍵移動飛船，空白鍵發射子彈。
2. 上方持續出現掉落的敵機，子彈擊中敵機加10分。
3. 敵機掉到底部或撞到玩家時，扣1條生命。
4. 加入爆炸粒子特效與流暢動畫。

05 / EXPORT & SUBMIT

下載遊戲，準備繳交。

HTML

這次要繳交的是 .html 網頁檔。下載後，用瀏覽器開啟並試玩。

作業一 / 一份遊戲 HTML

下載、驗證、重新命名。

  1. 從 Canvas 作品的下載／匯出功能取得 HTML。若沒有直接下載選項，可複製完整程式碼，以 UTF-8 存成 .html。
  2. 到下載資料夾找到檔案，雙擊開啟，實際試玩。確認副檔名不是 .html.txt。
  3. 檔名設為 班級座號姓名.html。
  4. 前往 Google Classroom作業繳交區，按「新增或建立」→「檔案」，上傳遊戲 HTML 並點選「繳交」。

請下載 Canvas 的遊戲作品，不要用瀏覽器「另存網頁」存下整段 Gemini 對話，也不要只交 Gemini 分享連結。
