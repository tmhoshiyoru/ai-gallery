# AI 程式設計作品展示

純靜態的學生作品展示與投票網站，支援班級分類、遊戲縮圖、類型篩選、隨機遊玩，以及可還原的投票識別碼。

## 使用

網站由 GitHub Pages 發布。新增作品後提交至預設分支，GitHub Actions 會自動更新清單並發布。

作品放在 `作品/<展覽資料夾>/<班級>/`；檔名統一為班級與兩位數座號，多份作品使用 `-01`、`-02` 區分。前台只顯示作品代碼。

- `config/exhibitions.json`：展覽設定，目前只有第一個AI程式。
- `config/publication.json`：排除誤繳或不發布的檔案。
- `npm run build`：更新清單並準備靜態網站。
- `npm ci` 後執行 `npm run thumbnails`：使用本機Chrome產生新增或變更作品的縮圖，再執行建置。
- `npm test`：執行資料、分類與投票編碼測試。

首次使用GitHub Pages，請在儲存庫Settings → Pages將來源設為GitHub Actions。

詳細操作請見 [使用說明](使用說明.md)、[投票流程說明](投票流程說明.md)及[新增展覽說明](新增展覽說明.md)。

## 本機管理資料

教師用Excel、檢查報告、暫存檔及已確認的Gemini誤繳對話檔不加入儲存庫。發布對照會保留歷史票單所需的作品代碼與版本索引，不會包含對話原文。

投票草稿儲存在各自瀏覽器，識別碼需自行交給老師；網站沒有自動收票或身分驗證服務。
